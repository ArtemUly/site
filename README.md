# Сайт ко Дню матери 💐

Интерактивный сайт-подарок жене ко Дню матери. Сейчас это викторина, но она —
один из этапов сценария (перед ней будут другие шаги).

## 🔗 Ссылки

- **Локально (под рукой):** http://localhost:8000
- **Публичная ссылка:** https://raw.githack.com/ArtemUly/site/main/index.html
- **Постоянная ссылка (после включения GitHub Pages):** https://artemuly.github.io/site/

## 📁 Структура проекта

```
index.html        — 3 экрана: приветствие → викторина → результат
css/style.css     — пастельный дизайн, лепестки, адаптив, анимации
js/quiz-data.js   — данные: intro + questions + results (вопросы редактируются здесь)
js/app.js         — логика: прогресс, проверка ответов, результат, конфетти
```

## 🚀 Как запустить локально

```bash
cd /Users/d.ulyanova/IdeaProjects/site
python3 -m http.server 8000 --bind 127.0.0.1
```

Открыть: http://localhost:8000

Остановить сервер:

```bash
lsof -ti:8000 | xargs kill
```

## ✏️ Как менять вопросы

Все вопросы и тексты — в `js/quiz-data.js`. Правильный ответ задаётся индексом
`correct` (нумерация с нуля: 0 — первый вариант, 1 — второй и т.д.).

```js
{
  question: "Текст вопроса?",
  options: ["Вариант 1", "Вариант 2", "Вариант 3"],
  correct: 1,
}
```
